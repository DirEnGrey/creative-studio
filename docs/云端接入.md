# 云端接入

此文件是待执行配置；不表示云端已经创建。建议环境名：创作工作室，仓库名：creative-studio，仓库和环境均仅自己可用。

## 接入步骤
1. 在 GitHub 创建空的私有仓库 creative-studio；将本目录内容推送到仓库。仓库由用户账户持有。
2. 在 Codex：设置 → Codex Cloud → Environments → Create environment；选择该仓库并 Get started。连接 GitHub 的授权由账户持有人完成。
3. 把本文件下方的配置提示词发到环境设置对话。
4. 检查环境配置、安装结果、Word／PPTX／PDF 样例与逐页检查图；有错误则先修复。
5. 保存并 Publish；等待 Environment published。用新云端任务复测，成功后才算完成。

官方流程：https://learn.chatgpt.com/docs/environments/cloud-environments

## 可直接粘贴的配置提示词

请把这个仓库配置为我的中文创作工作室，服务科幻小说、TVC 广告片、企业宣传片、纪录片、电影剧本的创作与修订，以及分镜设计 PPT。
读取 README.md 和 AGENTS.md。保留用户素材和原稿，按项目与版本管理文件；事实与虚构推演分开。
使用 Python 3.11 或更高版本。Install script 设置为 bash scripts/install.sh，并实际执行验证。
安装 requirements.txt 中的 Word、PPTX、图片和 PDF 工具，以及 LibreOffice Writer/Impress、Noto 中文字体、Poppler。工作目录使用仓库根目录，Python 使用 .venv/bin/python。
Start skill：确认当前目录，读取 AGENTS.md 和当前项目 brief，执行 .venv/bin/python tools/studio.py doctor --require-render。这里没有后台服务要启动。
网络使用 Package managers；需要的其他域名仅在实测发现缺失时添加。资料调研优先使用可用的网页搜索工具。环境访问选 Only me。不需要填写 API key；图像生成、在线文档或视频工具仅在相应工具已连接并获得授权时使用，不把本机连接当作云端已连接。
先生成中文 Word 与分镜 PPTX 测试文件，使用 LibreOffice 转为 PDF，并用 pdftoppm 渲染成图，逐页检查中文、溢出和图片比例。检查 JSON 分镜镜号唯一、时长为正、汇总时长正确；超长文本必须拆页或精简，不能静默截断。
测试文件写到 work/，保留检查日志。完成后报告已安装工具、版本、验证结果和未解决项，然后保存配置并准备发布。

## 验收标准
- 真实云端安装成功；doctor --require-render 退出码为 0。
- 生成并打开中文 DOCX、可编辑 PPTX、PDF，逐页检查没有乱码和溢出。
- 新项目可从模板初始化，重复项目名不会覆盖已有内容。
- 已发布环境可在新任务中选中；新任务复测成功。
- 本机初始化和文件结构测试不能替代以上云端验收。

## 持续保存
新任务从已发布环境开始，各任务的作品各自保存。重要稿件要提交回私有仓库或导出备份；不要把任务间文件自动同步当成已保证的功能。
